# Design-Challenge 22.10.2026 – Protokoll

Wie wir zum Status quo (`markenkern.md`) gekommen sind.

## Quellen

- Pinterest-Pinnwand **NOMAET.** (Anahitas Account, `anahitamiriamrehbein/nomaet`): Analog und Erinnerung, Polaroids, Fotostreifen, handgeschriebene Sätze, Scrapbook-Layouts, viel Schwarz-Weiß auf Off-White, einzelne kräftige Akzente.
- Tattoo-Schrift von Anahita & Sascha (PDF „Nomaet_Handschrift“): Fine-Line, Versalien, weit gesperrt, gestaffelt („NO / MATTER / WHAT“), „I ADORE YOU.“.
- Vorbild-Marke **Joseph Atelier** (josephatelier.de): Berliner Mode-Label eines Gründerpaars, Drops, 59–239 €, foto-getrieben, fette Wortmarke, keine Requisiten.
- Referenz-Submark braun/blau → Markenbraun Leder.

## Entscheidungen

| Thema | Entscheidung |
|---|---|
| Tintenrot | raus |
| Handschrift | Hauptelement; eigener Font aus eigener Hand im Tattoo-Stil (Tattoo-Künstlerin stimmt eher nicht zu) |
| Variante | **B „Album, reduziert“** gewonnen vor A „Archiv wie bisher“ und C „Foto zuerst“ |
| Post-it | aus A übernommen, nur Social und Karten |
| Stempelblau | nur Highlight, max. eine Stelle |
| Braun | **Leder `#6B4C3A`** aufgenommen (Box, Verpackung, Footer) |
| Wortmarke | „nomaet.“ in Boldonse steht; Zeichen noch offen |
| Haltungssatz | „for the ones that were meant to be.“ |
| Zielgruppe | Anahitas Community, Frauen 25–45 |

## Härtetests (Variante B)

| Test | Ergebnis |
|---|---|
